# OpenWorthy

OpenWorthy marks the email worth reading, on your own computer. It reads
message headers only, and nothing about you or your mail ever leaves your
computer.

This repository holds OpenWorthy's website, downloads and issue tracker. It
contains no source code.

- **Downloads:** [Releases](../../releases) — the first beta is on its way.
- **Problems and questions:** [Issues](../../issues).
- **Website:** https://openworthy.github.io — coming soon.
